Ranking or comparing categories?

Use bars, lollipops, Pareto-style ranking, or grouped bars. Horizontal bars help when labels are long.

Change over time?

Use a line chart for trend focus, an area chart for volume, or a Gantt chart when duration is the point.

How are values spread?

Use histograms for shape, box plots for compact summaries, and violin plots when comparing distribution shapes.

Correlation between variables?

Use scatter for two variables, bubble for three, regression for a fitted relationship, and network charts for dependencies.

Part of a whole?

Use treemaps for many items, stacked bars for comparable totals, sunbursts for hierarchy, and donut only with very few slices.

Flow between stages?

Use Sankey diagrams for weighted flows, funnels for stage drop-off, and trees for parent-child structure.

  • Process capability: control chart, capability view.
